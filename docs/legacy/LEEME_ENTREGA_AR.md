# LEEME — Entrega AR de revisión

Usa estos dos archivos para la demostración:

- `tarjeta-provisional.html?card=yadier-molina` — frente/reverso imprimible con QR.
- `ar-carta.html?card=yadier-molina` — experiencia AR.

El flujo es: QR del reverso → activar cámara → voltear tarjeta → reconocer el frente → pelota 3D.

Cambios principales de esta entrega:
- Sin cuadro azul de MindAR.
- El diseño completo de la tarjeta es el target.
- Pelota propia de tu compañero.
- Pelota quieta por defecto.
- Salto corregido para subir visualmente en pantalla.
- Giro manual y botón 360°.
- Zoom y movimiento con dos dedos.
- Confeti 3D ON/OFF.
- QR negro sobre blanco para mayor legibilidad al imprimir.
