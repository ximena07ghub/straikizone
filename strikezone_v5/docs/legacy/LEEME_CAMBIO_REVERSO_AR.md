# Cambio AR: reverso como marcador

Para Yadier Molina el flujo queda así:

1. Imprime la tarjeta desde `tarjeta-provisional.html?card=yadier-molina`.
2. Escanea el QR del reverso.
3. Abre `ar-carta.html?card=yadier-molina`.
4. Activa la cámara AR.
5. Sin voltear la tarjeta, apunta al mismo reverso completo.
6. MindAR reconoce `assets/cards/yadier-molina-back.png`.
7. Aparece `assets/models/pelota-yadier.glb`.

El QR abre la URL; el reverso completo (QR + tipografía + estadísticas + composición) funciona como target visual.

Controles: toque/Saltar = salto, 1 dedo = giro, 2 dedos = mover y zoom, Confeti ON/OFF, 360°, Reiniciar.
